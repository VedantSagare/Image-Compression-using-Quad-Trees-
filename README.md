# Image Compression using Quad Trees (C++)

This project implements **image compression using Quad Trees** in C++.  
Quad Trees recursively divide an image into homogeneous regions, achieving compression by storing only regions with significant variance.

---

## 🚀 Features
- Lossy image compression
- Quad Tree recursive decomposition
- Supports grayscale images (PGM format)
- Adjustable compression threshold
- Reconstructed compressed image
